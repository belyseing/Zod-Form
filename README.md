# React Hook Form with Zod Validation

This project is a simple React form using **React Hook Form** and **Zod** for input validation. It includes three input fields: **Name**, **Email**, and **Age**, each with specific validation rules and error messages.

## Features

- **React Hook Form** for efficient form management
- **Zod** for schema-based validation
- **Custom error messages**
- **Tailwind CSS** for responsive and clean UI

## Tech Stack

- React
- React Hook Form
- Zod
- @hookform/resolvers
- Tailwind CSS

## Validation Rules

| Field | Rule                                       |
| ----- | ------------------------------------------ |
| Name  | Minimum 5 characters                       |
| Email | Must be a valid email address              |
| Age   | Must be a number and at least 18 years old |
